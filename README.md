В рамках работы было разработано Android-приложение на Kotlin, демонстрирующее основные способы взаимодействия между Activity с использованием Intent. Реализованы переходы между двумя активностями, передача примитивных данных и объектов через Parcelable, получение результата от второй Activity с использованием API контрактов результата. Дополнительно показано использование неявных интентов для открытия веб-ссылки в браузере и запуска камеры для съёмки фотографии. Интерфейс построен на двух XML-разметках с набором кнопок, каждая из которых отвечает за отдельный пункт задания.
